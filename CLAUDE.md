# Working on TorchSX

## Branches

Name every branch after the problem it addresses, e.g. `claude/torchref-0.8-upgrade`
or `claude/fix-completeness-imports`, never a generated name such as
`claude/kind-dijkstra-kexpnn`. This also holds when a session was handed a
generated branch name: create the problem-specific branch from `master` and work
there. One problem per branch; unrelated changes go on a branch of their own.
